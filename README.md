# EngiPocket 📱⚡
> **Mobile Engineering Companion for Engineering Students**

Ứng dụng web di động hỗ trợ sinh viên các ngành Kỹ thuật (Điện - Điện tử, Tự động hóa, Cơ điện tử, CNTT) với giao diện tối ưu trên smartphone.

---

## ✨ Tính năng nổi bật

- 📐 **Công cụ tính toán kỹ thuật:**
  - Quy đổi số phức dạng đại số ($a + jb$) và dạng cực ($r\angle\theta^\circ$).
  - Tính định thức ma trận cấp 2 và ma trận nghịch đảo $A^{-1}$.
  - Cầu phân áp điện trở (Voltage Divider).
  - Có hiển thị từng bước giải (Step-by-step breakdown) để tự đối chiếu.

- 📖 **Cẩm nang công thức cốt lõi:**
  - Tra cứu nhanh bảng biến đổi Laplace, chuỗi Fourier, công thức Euler, định luật Ohm...
  - Bộ lọc theo danh mục & tìm kiếm tức thì.

- 🎓 **Luyện thi trắc nghiệm:**
  - Ngân hàng câu hỏi trắc nghiệm kỹ thuật kèm giải thích chi tiết và lưu kỷ lục điểm cao.

- ⏰ **Đếm ngược Deadline:**
  - Quản lý hạn nộp bài tập lớn, lịch thi giữa kỳ, cuối kỳ với tính năng đếm ngược thời gian thực.
  - Lưu trữ dữ liệu an toàn trên trình duyệt (LocalStorage).

---

## 🚀 Trải nghiệm ứng dụng

Chỉ cần mở trực tiếp file `index.html` trên bất kỳ trình duyệt nào (Chrome, Safari, Edge trên điện thoại hoặc máy tính) mà không cần cài đặt thêm phần mềm.
